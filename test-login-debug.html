🔬 Login Cookie Debug Test

Diagnose why /auth/me returns old user after new login

⚠️ Issue Identified

When you login as User B, the backend returns User B's data in the login response, but /auth/me immediately returns User A's data.

Root Cause: The cookies set during login are for User A, not User B. This test will help identify why.

📋 Test Configuration

Step 1: Check Current Cookies PENDING

Check what cookies are currently stored before login

Step 2: Clear All Cookies PENDING

Attempt to clear all cookies (JavaScript can only clear non-HttpOnly cookies)

Step 3: Perform Login PENDING

Login with the credentials above and capture the response

Step 4: Check Cookies After Login PENDING

Verify what cookies were set after successful login

Step 5: Test /auth/me PENDING

Call /auth/me and see what user data is returned

Step 6: Compare Data PENDING

Compare login response vs /auth/me response
